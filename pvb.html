Pure vs Box — why the box prior reads lower

The box prior reads lower than pure RAPM for stars (e.g. Jokić pure ≈ +7.6 but box ≈ +1.4). This is correct, intentional shrinkage — not a bug. The box prior is a conservative estimate built from box-score stats, which simply can't see a lot of impact (especially defense). This page shows the gap per factor and decomposes why: each factor's box retention is box-mapping skill × cross-league translation (plus a per-player early-career reliability ramp). It is not one uniform contraction, and the cross-league translate step can even amplify some factors.
